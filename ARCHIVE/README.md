# Archivio versioni contrattuali

Questa cartella è destinata esclusivamente alle versioni superate del Master, degli allegati e dei template firmabili.

## Regole

- Nessun documento in `ARCHIVE/` deve essere utilizzato per nuove prenotazioni.
- Le versioni superate non devono essere cancellate se sono state utilizzate per soggiorni già sottoscritti.
- Ogni documento archiviato deve conservare numero versione e data di efficacia.
- Il README principale del repository identifica sempre il Master corrente.
- I pacchetti effettivamente sottoscritti dagli Ospiti devono essere conservati nel sistema documentale operativo con log e allegati applicabili; questo repository contiene i master e i template, non sostituisce l'archivio probatorio delle singole firme.
